# Reetdeef Quest (web)

Play it: https://muellercodes.github.io/reetdeef-quest-web/

Toby's Stuffie-verse game, made from his stuffed animals and his Reference Book. This repo only
publishes the web build; the game itself lives in a private repo. Each new build is uploaded to
the "latest" release and the workflow puts it online.

Keyboard and mouse, a controller, or touch on a phone or tablet. The first load is about 75 MB.
